# 正式项目模板整理计划

目标：保留已验证的文件同步与道路制图能力，把真实资料、模拟数据、生成物分开；从目的地认知到复盘有清晰入口，能够创建不携带亚庇数据的新项目。用户已授权本地整理，暂不操作 Git/GitHub。

1. 迁移测试夹具到 `tests/fixtures/kota-kinabalu/`，历史证据到 `tests/evidence/2026-10-21/`，可重建样例到 `tests/output/`；记录路径对应并核对迁移前后文件摘要。
2. 以 `travel/destinations/<id>/` 保存可复用目的地知识，以 `travel/trips/<id>/` 保存本次需求、筛选、日计划、决策、日志、复盘。建立亚庇草稿，仅迁入有来源的候选知识、用户指定酒店与汽车偏好；模拟选择不导入。
3. 提供一个项目入口：创建新项目、目的地、旅程、校验草稿、构建/校验单日攻略、补充道路缓存和本地预览。现有渲染器保留；草稿空行程可保存，但不能生成假行程。正式命令默认不读取测试资料。
4. 更新本地 Skill、模板、数据约定与全流程说明；知识/选择/经历各有唯一来源，地图和攻略只由源数据生成，复盘仅按需生成。
5. 验证：原有回归；新项目无真实或模拟资料泄漏；新旅程没有默认景点/假偏好；草稿可检查；用隔离夹具完成构建和取消重排；候选未完成数据不妨碍已确认景点；错误路径/重复创建不覆盖已有内容。检查文档链接与 Skill 格式，并做一次独立复核。

边界：整理和复用现有能力，不扩展多日全局优化、实时车费、其他交通模式或 QGIS。目录允许多个日计划，生成器仍逐日运行；现有费用计算仍为 MYR 已知门票小计。
